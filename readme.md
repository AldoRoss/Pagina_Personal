# README

## Iniciar servidor web

1. Clonar repositorio
2. Ejecutar `npm install` para instalar las librerias
3. Ejecutar `npm run dev` para iniciar el servidor

# Node.js

Es necesario tener instalado [Node.js](https://nodejs.org/en/download/prebuilt-installer/current) y npm que regularmente se instala con Node.js.
